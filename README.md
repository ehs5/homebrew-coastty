# Homebrew tap for Coastty

[Coastty](https://github.com/ehs5/coastty) is a macOS terminal, built on Ghostty, that shows which of your coding agents are working and which are waiting for you.

```sh
brew install --cask ehs5/coastty/coastty
```

`brew upgrade` keeps it up to date. Coastty is not yet signed with an Apple Developer ID, so macOS blocks the first launch; the [Coastty README](https://github.com/ehs5/coastty#install) explains how to approve it.
